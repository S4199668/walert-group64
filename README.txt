# Group 64 – Test-Driven RAG

A Retrieval-Augmented Generation (RAG) system that answers student questions about RMIT assessment extension policies, procedures, and eligibility, built on official RMIT documentation.

## Project Goal
Develop and evaluate a RAG pipeline that retrieves accurate policy information to answer student queries about assessment extensions.
